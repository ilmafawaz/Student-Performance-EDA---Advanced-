# Student-Performance-EDA-Advanced-
This project performs an advanced Exploratory Data Analysis (EDA) on a student academic performance dataset to understand how demographic, socio-economic, and preparation-related factors influence student outcomes. The analysis combines data cleaning, univariate, bivariate, and multivariate exploration, followed by a dashboard for clear, non-technical storytelling.

##Dataset
students_performance.csv

##Dashboard
- Score distributions
- Performance comparisons across demographic groups
- High-level insights for quick interpretation

##Key Insights
- Students who completed test preparation courses achieve higher overall scores
- Standard lunch students outperform those with free/reduced lunch on average
- Female students slightly outperform male students in total score
- Higher parental education levels are positively associated with performance
